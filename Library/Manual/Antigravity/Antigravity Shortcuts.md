# 常用

- 打开 Agent Chat ： `Ctrl + L`
- 打开 Terminal ：Ctrl + \`
- 分离窗口：` Ctrl + \`
- 搜索文件：`Ctrl + P`
- 搜索会话：`Ctrl + K`
- 创建新会话：`Ctrl + N`
- 行内编辑：`Ctrl + I`
- 打开 Settings：`Ctrl + ，`
- 打开命令面板：`Ctrl + Shift + P`
