# 创建文件夹

`mkdir -p 路径` 用来创建目录，并自动创建缺失的父级目录。

`-p` 是 `parents` 的意思。

例如：

```
mkdir -p notes/2026/08
```

即使 `notes` 和 `2026` 都还不存在，也会一次性创建完整层级。

它还有一个好处：如果目标文件夹已经存在，不会报错。

没有 `-p` 时：

```
mkdir notes/2026/08
```

若 `notes/2026` 不存在，命令会失败。
