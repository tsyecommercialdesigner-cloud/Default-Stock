# 手动关闭 Python 服务的方法

如果您以后在本地终端启动了 Python 服务（如 `python -m http.server 3000`），可以通过以下方法手动关闭：
## 1. 前台终端窗口（最简单）
在运行该命令的终端窗口中直接按下快捷键：
```bash
Ctrl + C
```

## 2. PowerShell 中手动关闭
* **指定端口关闭（推荐，不影响其它 Python 程序）：**
  ```powershell
  Stop-Process -Id (Get-NetTCPConnection -LocalPort 3000).OwningProcess -Force
  ```
* **强制关闭所有 Python 进程：**
  ```powershell
  Stop-Process -Name "python" -Force
  ```

## 3. CMD (命令提示符) 中手动关闭
* **查找占用 3000 端口的进程 ID (PID)：**
  ```cmd
  netstat -ano | findstr :3000
  ```
* **通过 PID 强制终止：**
  ```cmd
  taskkill /PID <PID> /F
  ```
* **强制关闭所有 python.exe 进程：**
  ```cmd
  taskkill /IM python.exe /F
  ```
