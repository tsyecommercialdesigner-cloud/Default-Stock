在遇到 443 端口连接失败或超时时，可以通过镜像站或加速服务来拉取 GitHub 仓库。

你可以使用以下几种方式：

## **1\. 使用 GitCode 镜像（推荐）**

直接将原链接中的 github.com 替换为 gitcode.net，GitCode 会自动代理拉取 GitHub 的仓库：

```bash
git clone https://gitcode.net/zhongerxin/cowart.git
```

## **2\. 使用 K308 / FastGit 等第三方加速镜像**

国内有一些开源社区提供的加速节点，可以直接在 URL 中添加加速前缀或替换域名：

### **选项 A：使用 FastGit 镜像域名**

将 github.com 替换为 hub.fgit.ml 或 hub.fastgit.xyz：

```bash
git clone https://hub.fgit.ml/zhongerxin/cowart.git
```

### **选项 B：使用 k308 加速代理**

在原 URL 前加上加速前缀 \[https://git.k308.io/\](https://git.k308.io/)（或 \[https://ghproxy.com/\](https://ghproxy.com/)）：

```bash
git clone https://git.k308.io/https://github.com/zhongerxin/cowart.git
```

## **3\. 导入到 Gitee（码云）拉取**

如果镜像站不稳定，最稳妥的方法是将该仓库**导入到国内的 Gitee**：

> 1. 登录 [Gitee](https://gitee.com/) 账号。  
> 2. 点击右上角的 **\+** $\\rightarrow$ **新建仓库** $\\rightarrow$ **导入已有仓库**。  
> 3. 填入原 GitHub 链接：\[https://github.com/zhongerxin/cowart.git\](https://github.com/zhongerxin/cowart.git)。  
> 4. 导入完成后，复制 Gitee 生成的仓库链接进行 git clone 即可。

```bash
git clone https://gitee.com/lsreback/Cowart $HOME/plugins/cowart
```

**💡 小贴士：拉取后的 Remote 配置修正**  
通过镜像站 clone 下来的仓库，默认的远程地址（remote）会指向镜像站。为了后续能够正常提交或跟进原项目更新，建议克隆成功后进入项目目录，将远程地址改回原 GitHub 地址：

```bash
cd cowart  
git remote set-url origin https://github.com/zhongerxin/cowart.git  
```
