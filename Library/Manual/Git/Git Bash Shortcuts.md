# 常用

## 复制与粘贴

使用键盘：

- 复制：`Ctrl + Ins`；或选中代码后，按 `Ctrl + Shift + C`
- 粘贴：`Shift + Ins`； `Ctrl + Shift + V`

使用鼠标：

- 复制：用鼠标选中文本后通常会自动复制到主选择剪贴板
- 粘贴：右键单击终端窗口，或按鼠标中键

设置入口：

若 `Ctrl + Shift + C/V` 没有生效，打开 Git Bash 窗口左上角菜单，进入 `Options` → `Keys`，检查复制和粘贴快捷键设置。
